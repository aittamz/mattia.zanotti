Il tuo spazio di lavoro

AGGIORNA.

Scrivi nei campi, controlla l’anteprima e pubblica il file aggiornato su GitHub. Il CV si gestisce separatamente.

Come pubblicare le modifiche
  1. Modifica i contenuti in italiano e in inglese. I titoli di pubblicazioni, interventi e podcast rimangono nella lingua originale.
  2. Premi Anteprima per controllare la bozza.
  3. Premi Copia il file aggiornato, poi Apri il file su GitHub. Accedi al tuo account, seleziona tutto il contenuto del file, incolla e premi Commit changes.
  4. Attendi la pubblicazione di GitHub Pages e ricarica il sito. Puoi anche scaricare il file per conservarne una copia.

La bozza si salva in questo browser, quando lo spazio locale è disponibile. Non viene pubblicata automaticamente. Questa pagina non dà accesso in scrittura al sito: la pubblicazione richiede il tuo account GitHub.
