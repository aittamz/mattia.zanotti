# Mattia Zanotti — sito personale

Sito statico HTML/CSS, pubblicato da GitHub Pages dal ramo main, cartella radice.

## Modificare i contenuti

- `index.html`: homepage, pubblicazioni, progetti, richiamo al podcast e mappa.
- `cv.html`: curriculum; i testi IT/EN sono anche nell’oggetto `testi` in fondo al file. Il pulsante stampa permette di salvare un PDF nella lingua visualizzata.
- `PODCAST.html`: serie podcast. Copiare una scheda `.podcast-card` per aggiungerne un’altra.
- `mappa-conferenze.html`: elenco delle presentazioni e dati della mappa.
- `assets/material-digital.css`: grafica condivisa da tutte le pagine, responsive compreso.
- `assets/sources/`: fotografie e materiali originali forniti dall’autore, ottimizzati per il web. Ritagli e colori sono applicati in CSS.

Per aggiornare: aprire il file su GitHub, premere Modifica e salvare con un commit. Non occorrono compilazione o dipendenze. Le mappe richiedono una connessione Internet.
